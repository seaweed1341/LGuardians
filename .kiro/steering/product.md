# Product overview

LGuardians is a prototype dashboard for collaborative security review. It presents issues, agent workflow, attack/defense rounds, verification results, and a human review step. The current repository is frontend demo code with sample data, not a working security scanner.

Primary views: security dashboard, workflow board, and issue detail (information preparation, battle, result). The intended user is an internal developer or reviewer who examines evidence and decides how to handle a proposed fix.

Preserve the visible information architecture and the distinction between an agent's action and a human approval when connecting real data.
