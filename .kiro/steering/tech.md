# Technology and constraints

Vanilla HTML, CSS and browser JavaScript; no bundler or framework conversion.
State lives in memory. A refresh resets the demo. Keep 30 sample issues and
two detailed executable scenarios unless the user requests otherwise.

Violet primary UI, Indigo defense, red attack. Reuse existing map, battle and
external artwork. BinBird default pose uses stand.webp, not standing.webp.
No real tokens, internal API keys or customer data may be committed.

Code exploration, one-shot testing, deployment, comment transmission and OSS
submission are simulated. Future integration must centralize API calls and
display loading/error states before replacing local mutations.
